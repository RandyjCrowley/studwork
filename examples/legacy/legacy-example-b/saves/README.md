# Sample old saves (synthetic)

Each JSON file is one DataStore entry exactly as ProfileService stored it (store `PlayerData`,
key `Player_<userId>`): the profile's `Data` plus ProfileService's `MetaData` and `GlobalUpdates`.
No real player's data: the user ids are made up.

- `player-2001.json`: a typical player, session released.
- `player-2002.json`: a player with a full pet list (20 pets: owns ExtraSlots) and gem-pack purchases.
- `player-2003.json`: a brand-new player (template data).
