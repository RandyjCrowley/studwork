# Sample old saves (synthetic)

Each JSON file is one DataStore entry exactly as this game wrote it: `store` (the DataStore name),
`key`, and `value`. No real player's data: the user ids are made up.

- `player-1001.json`: a typical player.
- `player-1002.json`: an early player whose save predates `lastDaily` and `settings.sfx`.
- `player-1003.json`: a player who owns everything.
- `purchase-history.json`: entries of the `PurchaseHistory` store (one per granted receipt).
