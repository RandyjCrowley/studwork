# Using StudWork from a games repo

Planned for StudWork v1.4.0: games live in a separate repo that has this repo as a git submodule
(`roblox-core/`, pinned at a release tag) and run the core's tools against their own `games/`
folder. Until v1.4.0 is released, the core's tools work on this repo only (`examples/`,
`templates/`).
