# Framework requests

This game never edits `studwork/` (the StudWork framework submodule). When the game needs something
from StudWork, add an entry here (or open an issue on the StudWork repository); the framework is
changed there and shipped in a release tag, then this project bumps its submodule in its own commit
(what changed: `studwork/CHANGELOG.md`).
