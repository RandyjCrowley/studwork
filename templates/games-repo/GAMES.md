# Games

One row per game. Each game is its own Roblox experience with a test place and a live place.
`tools/new-game <name>` adds rows automatically.

`Core` = the StudWork version/commit the game was last published with (`tools/publish` writes it,
dry runs included; `tools/framework-status` compares every game with the pinned `roblox-core/`).
