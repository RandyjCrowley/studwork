# Player kit

Codes provides free promotion rewards and durable global use limits. Settings provides an extensible preference schema and owner-only saved values. Enable either module independently through its normal module reference.

See [the kit guide](../../../docs/framework/kits/player.md) for config, APIs, accessibility, persistence and override levels. Codes optionally uses Economy, Inventory, Rarity and Rebirth; Settings has no dependencies. All networking and saves use the public module API.
